# Nexora 1.0.0

First public release.

## Features
- Litecoin HD-wallet payments (Kraken/Coinbase rate lock, BlockCypher + litecoinspace fallback)
- Customer accounts, admin dashboard, 2FA (admin + customer)
- Signed offline license (ed25519, customer/expiry/features watermark)
- i18n (en, vi, zh, es, de)
- Signed integrity manifest for tamper detection
- Docker Compose 3-mode (local / HTTPS-domain / Cloudflare Tunnel)
- In-place auto-update via Docker images + FileServer
- Ops scripts: backup, restore-drill, go-live-check, support-bundle

## Audited
- 22/22 e2e + 35/35 unit
- Encryption key strict in production
- Auth/2FA/IDOR/rate-limit pen-test pass
