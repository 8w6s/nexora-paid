# Nexora LTS — Set it and forget it

The same Nexora storefront, but **shipped as a frozen build that never auto-updates**.

If you've ever been burned by a "routine update" breaking your shop, this is for you. You pay once, you get the current stable build, and that exact code runs forever. No surprise migrations. No deprecated features. No "we changed the admin UI again". Same shop on day 1 and day 1825.

## Who LTS is for

- You sell something stable and don't need new features
- You hate being on the receiving end of vendor change-logs
- You run multiple shops and want one of them locked in a known-good state
- You're paranoid about update flow touching customer data (it shouldn't — but LTS guarantees it can't)

## What LTS includes

- Full Nexora storefront — same feature set as the regular License
- Per-invoice Docker image, frozen at the version you purchased
- Signed `.license` file
- One-command install
- **Critical security patches** — case-by-case, shipped directly to you by email when a real vulnerability is found. Feature updates do not apply.
- Lifetime — no expiry, no recurring fee

## What LTS does NOT include

- Feature updates (the whole point — your shop won't change underneath you)
- New plugins or admin UI redesigns
- Migration to future major versions

If you want updates, buy the regular **Nexora License** instead.
